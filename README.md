# BotW Yemek Hesaplayıcı

Zelda: Breath of the Wild için pişirme hesaplayıcı. Tencereye 5 malzemeye kadar koy, yemeğin adını, kaç kalp verdiğini, etkisini ve süresini gör. Elimdekiler sekmesinde telefon kamerasını televizyona tutup envanterini okutabilir, elindekilerle yapabileceğin en iyi yemekleri bulabilirsin.

iPhone'da Safari ile aç, Paylaş > Ana Ekrana Ekle. Uygulama internetsiz de çalışır.

Sayılar oyun dosyalarından çıkarılmış topluluk verisine dayanır (Pistonite/botw-recipe, savage13/cooking). Malzeme görselleri oyundandır, Zelda Wiki üzerinden alınmıştır. Hayran yapımıdır, Nintendo ile ilgisi yoktur.
