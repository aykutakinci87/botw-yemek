# BotW Yemek Hesaplayıcı

Zelda: Breath of the Wild için pişirme hesaplayıcı. Tencereye 5 malzemeye kadar koy, yemeğin adını, kaç kalp verdiğini, etkisini ve süresini gör. Elimdekiler sekmesinde telefonu yatay tutup televizyona çevir, "Kamerayla tek tek tara"ya bas: oyunda imleç hangi malzemenin üstündeyse uygulama adını okur, sen sayısına dokunarak eklersin. Sonra elindekilerle yapabileceğin en iyi yemekleri bulur.

iPhone'da Safari ile aç, Paylaş > Ana Ekrana Ekle. Uygulama internetsiz de çalışır.

Sayılar oyun dosyalarından çıkarılmış topluluk verisine dayanır (Pistonite/botw-recipe, savage13/cooking). Malzeme görselleri oyundandır, Zelda Wiki üzerinden alınmıştır. Yazı tanıma için tesseract.js (Apache-2.0) kullanılır, dosyaları ocr/ klasöründedir. Hayran yapımıdır, Nintendo ile ilgisi yoktur.
